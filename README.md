## 1. Лабораторийн ажлын зорилго

Энэхүү лабораторийн ажлын зорилго нь орчин үеийн UI автоматжуулалтын хэрэгсэл болох Playwright ашиглан веб системийн функционал тестийг автоматжуулах, тестийн үр дүнг шалгах, алдааг илрүүлэх болон тайлагнах арга барилд суралцахад оршино.

Лабораторийн ажлын хүрээнд дараах зорилтуудыг хэрэгжүүлсэн.

- Playwright тестийн орчныг суулгаж тохируулах.
- TypeScript ашиглан автомат тестийн скрипт бичих.
- Веб системд амжилттай болон амжилтгүй нэвтрэх үйлдлийг шалгах.
- Нэвтэрсний дараах бараа сагслах үйлдлийг автоматжуулах.
- Assertion ашиглан тестийн үр дүнг баталгаажуулах.
- Codegen хэрэгслийг турших.
- Trace Viewer ашиглан тестийн алдааг шинжлэх.
- HTML Report ашиглан тестийн үр дүнг тайлагнах.
- Git болон GitHub ашиглан төслийн хувилбарын удирдлага хийх.

## 2. Ашигласан технологи, хэрэгслүүд

### 2.1. Playwright

Playwright нь Microsoft-ийн хөгжүүлсэн, веб хөтчийн ажиллагааг автоматжуулах нээлттэй эхийн хэрэгсэл юм.

Playwright нь Chromium, Firefox болон WebKit хөтчүүдийг дэмждэг бөгөөд UI автомат тестийг найдвартай гүйцэтгэх боломжтой.

### 2.2. TypeScript

TypeScript нь JavaScript дээр суурилсан, өгөгдлийн төрлийн шалгалттай программчлалын хэл юм.

Энэ лабораторийн автомат тестүүдийг TypeScript хэлээр бичсэн.

### 2.3. Node.js болон npm

Node.js нь JavaScript болон TypeScript дээр суурилсан хөгжүүлэлтийн хэрэгслүүдийг ажиллуулах орчин юм.

npm нь Playwright болон шаардлагатай сангуудыг суулгах, удирдахад ашиглагдсан.

### 2.4. Visual Studio Code

Visual Studio Code ашиглан тестийн код бичих, засварлах, Terminal дээр команд ажиллуулах болон төслийн файлуудыг удирдсан.

### 2.5. Git болон GitHub

Git ашиглан төслийн өөрчлөлтүүдийг commit хэлбэрээр бүртгэж, GitHub репозиторт байршуулан хадгалах боломжийг бүрдүүлсэн.

## 6. Locator болон Assertion ашиглалт

Playwright-ийн орчин үеийн locator болон assertion боломжуудыг ашигласан.

### 6.1. Locator

Жишээ:

```typescript
page.getByPlaceholder('Username')
page.getByPlaceholder('Password')
page.getByRole('button', { name: 'Login' })
page.getByText('Products')
page.locator('[data-test="add-to-cart-sauce-labs-backpack"]')
```

### 6.2. Assertion

Жишээ:

```typescript
await expect(page).toHaveURL(/inventory.html/);
await expect(page.getByText('Products')).toBeVisible();
await expect(page.locator('.shopping_cart_badge')).toHaveText('1');
```

Assertion нь бодит үр дүнг хүлээгдэж буй үр дүнтэй харьцуулан шалгадаг.

### 6.3. XPath-аас зайлсхийсэн шалтгаан

XPath нь DOM бүтцийн өөрчлөлтөөс хамааран эвдрэх эрсдэлтэй, ялангуяа элементийн байрлалд тулгуурласан XPath ашигласан үед.

Playwright-ийн `getByRole`, `getByText`, `getByPlaceholder` зэрэг locator нь хэрэглэгчид харагдах мэдээлэл болон элементийн зориулалтад тулгуурлан ажилладаг.

Мөн `data-test` атрибут ашиглах нь тестийн элементийг тогтвортой тодорхойлоход тохиромжтой.

Иймээс боломжтой нөхцөлд XPath-ийн оронд орчин үеийн locator ашиглахыг сонгосон.

## 8. Playwright Codegen

Playwright Codegen нь веб хөтөч дээр хийсэн үйлдлийг автоматаар тестийн код болгон үүсгэдэг хэрэгсэл юм.

Ажиллуулах команд:

```bash
npx playwright codegen https://www.saucedemo.com/
```

Codegen-ийн тусламжтай нэвтрэх, товч дарах, бараа сонгох зэрэг үйлдлээс locator болон тестийн код үүсгэх боломжтой.

Гараар бичсэн тестийн давуу тал нь үйлдлийн логик, assertion болон тестийн бүтцийг өөрийн шаардлагад нийцүүлэн хянах боломжтой байдаг.

Codegen нь тестийн эхний хувилбарыг хурдан үүсгэхэд тусалдаг боловч үүссэн кодыг шалгаж, шаардлагатай assertion-уудыг нэмж сайжруулах хэрэгтэй.

## 9. Trace Viewer ашиглан алдаа шинжлэх

Trace Viewer нь автомат тестийн гүйцэтгэлийн алхмууд, DOM snapshot, screenshot болон алдааны мэдээллийг шинжлэх боломжтой хэрэгсэл юм.

Trace үүсгэх команд:

```bash
npx playwright test test/mytest.spec.ts --project=chromium --trace on
```

Trace Viewer нээх команд:

```bash
npx playwright show-trace test-results/trace.zip
```

*Тайлбар: Дээрх `trace.zip` зам нь жишээ бөгөөд бодит тестийн үүсгэсэн trace файлын замыг ашиглана.*

### 9.1. Санаатай алдаа үүсгэсэн туршилт

Амжилттай нэвтрэх тестийн URL шалгах assertion-ийг зориудаар буруу болгосон.

Буруу assertion:

```typescript
await expect(page).toHaveURL(/wrong-page.html/);
```

Бодит веб хуудасны URL:

```text
https://www.saucedemo.com/inventory.html
```

### 9.2. Илэрсэн алдаа

```text
Error: expect(page).toHaveURL(expected) failed

Expected pattern: /wrong-page.html/
Received string: "https://www.saucedemo.com/inventory.html"
Timeout: 5000ms
```

Тест буруу URL хүлээж байсан тул assertion амжилтгүй болсон.

### 9.3. Алдааг засварласан байдал

Assertion-ийг дараах байдлаар зассан.

```typescript
await expect(page).toHaveURL(/inventory.html/);
```

Засвар хийсний дараа бүх 3 тест амжилттай ажилласан.

### 9.4. Дүгнэлт

Trace Viewer ашигласнаар тестийн алдаа гарсан алхмыг тодорхойлж, хүлээгдсэн болон бодит үр дүнгийн зөрүүг шинжлэх боломжтой болсон.

Энэ туршилтад веб систем зөв ажиллаж байсан бөгөөд алдаа нь тестийн буруу assertion-оос үүссэн болохыг тогтоосон.

## 11. Playwright ба Selenium-ийн харьцуулалт

1. Playwright болон Selenium нь веб системийн UI автомат тестийг гүйцэтгэхэд ашигладаг, Apache 2.0 лицензтэй нээлттэй эхийн хэрэгслүүд юм.
2. Playwright нь auto-wait боломжтой учраас элемент үйлдэл хийхэд бэлэн болохыг автоматаар хүлээдэг.
3. Selenium-д зарим нөхцөлд explicit wait ашиглах шаардлага гардаг бол Playwright нь олон нийтлэг хүлээлтийг автоматаар зохицуулдаг.
4. Playwright нь Chromium, Firefox, WebKit хөтчүүдийг дэмждэг бол Selenium нь WebDriver технологид суурилдаг.
5. Selenium нь Java, Python, C#, JavaScript зэрэг олон хэлтэй ажиллах өргөн экосистемтэй.
6. Playwright-ийн Codegen хэрэгсэл нь хэрэглэгчийн үйлдлийг автомат тестийн код болгон үүсгэх боломжтой.
7. Playwright-ийн Trace Viewer нь тестийн гүйцэтгэлийн алхмууд болон алдааны мэдээллийг нарийвчлан шинжлэхэд тусалдаг.
8. Selenium-д мөн лог, screenshot болон бусад debugging хэрэгслүүдийг ашиглах боломжтой.
9. Энэ лабораторийн туршилтаар Playwright ашиглан 3 функционал тестийг амжилттай автоматжуулсан.
10. Миний хувьд Playwright нь TypeScript-тэй уялдаа сайтай, тест бичих болон алдааг шинжлэх хэрэгслүүд нь нэг орчинд багтсан учраас энэ лабораторийн ажилд тохиромжтой сонголт болсон.
